# 李聖諺 Resume Site

Minimal static resume website for GitHub Pages.

## Stack

- HTML
- CSS
- JavaScript

No framework, no build step, no package manager.

## Files

- `index.html`: page content
- `styles.css`: minimalist layout and responsive styling
- `script.js`: mobile menu, active navigation, reveal animation, copy email, print action

## GitHub Pages

Upload these files to a GitHub repository and enable GitHub Pages from the repository root.
